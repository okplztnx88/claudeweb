# Kardari

*Language of the Caeldor*

## Overview

**Family:** Descended from ancient classical language
**Speakers:** vast
**Status:** thriving

**Influences:**
- neighboring tribal tongues
- merchant pidgin
- trade language

## Phonology

**Consonants:** minimal with 10-15 consonants
**Vowels:** complex with vowel length distinctions
**Syllable Structure:** strict phonotactic rules
**Stress:** penultimate stress


**Tone System:** 3-tone system



**Distinctive Features:**
- creaky voice
- long/short distinctions


## Grammar

**Word Order:** OVS
**Alignment:** active-stative
**Complexity:** highly analytical

### Case System

**Count:** 2-3 cases
**Cases:** instrumental, accusative
**Marking:** particles

### Verb System

**Tenses:** near past, perfect, past, remote future, imperfect, near future
**Aspects:** imperfective, completive
**Moods:** potential, indicative, imperative, optative
**Voice:** causative, reciprocal, middle, active
**Agreement:** agrees with both subject and object

### Noun System

**Gender:** no grammatical gender
**Number:** no number marking
**Definiteness:** suffixed definiteness
**Possession:** possessive particles

## Writing System


This language has no writing system and exists solely in oral tradition.
