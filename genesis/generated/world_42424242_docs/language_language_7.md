# Shalwen

*Language of the Draim*

## Overview

**Family:** Creole of multiple languages
**Speakers:** large
**Status:** stable

**Influences:**
- trade language
- merchant pidgin
- religious liturgy

## Phonology

**Consonants:** heavy on stops and nasals
**Vowels:** minimal 3-vowel system
**Syllable Structure:** open syllables preferred
**Stress:** fixed on last syllable




**Distinctive Features:**
- creaky voice
- glottalization


## Grammar

**Word Order:** VSO
**Alignment:** tripartite
**Complexity:** polysynthetic

### Case System

**Count:** 4-6 cases
**Cases:** dative, accusative, ablative, absolutive
**Marking:** word order

### Verb System

**Tenses:** past, near future, remote future, imperfect, remote past
**Aspects:** progressive, inceptive
**Moods:** imperative, conditional, subjunctive, potential
**Voice:** causative, active, middle
**Agreement:** minimal agreement

### Noun System

**Gender:** no grammatical gender
**Number:** singular/plural
**Definiteness:** definiteness by context
**Possession:** alienable/inalienable distinction

## Writing System


**Type:** abjad (consonant-only)
**Direction:** top to bottom
**Characters:** 140
**Materials:** clay tablets, metal plates
**Literacy:** restricted to elite
**Age:** recent (100-500 years)
