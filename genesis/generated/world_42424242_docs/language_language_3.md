# Altaian

*Language of the Noroni*

## Overview

**Family:** Part of larger language family
**Speakers:** moderate
**Status:** stable

**Influences:**
- religious liturgy

## Phonology

**Consonants:** rich in fricatives
**Vowels:** minimal 3-vowel system
**Syllable Structure:** open syllables preferred
**Stress:** unpredictable


**Tone System:** 2-tone system




## Grammar

**Word Order:** SOV
**Alignment:** nominative-accusative
**Complexity:** polysynthetic

### Case System

**Count:** 4-6 cases
**Cases:** genitive, nominative, accusative, locative
**Marking:** word order

### Verb System

**Tenses:** remote past, remote future, future, near past, imperfect, past
**Aspects:** perfective, progressive
**Moods:** subjunctive, potential
**Voice:** passive, middle, causative
**Agreement:** agrees with both subject and object

### Noun System

**Gender:** no grammatical gender
**Number:** singular/paucal/plural
**Definiteness:** definite/indefinite articles
**Possession:** possessive affixes

## Writing System


This language has no writing system and exists solely in oral tradition.
