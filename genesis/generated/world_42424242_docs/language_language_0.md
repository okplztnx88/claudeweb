# Kardari

*Language of the Shalim*

## Overview

**Family:** Isolate (no known relations)
**Speakers:** small
**Status:** stable

**Influences:**
- trade language
- religious liturgy

## Phonology

**Consonants:** heavy on stops and nasals
**Vowels:** vowel harmony required
**Syllable Structure:** open syllables preferred
**Stress:** unpredictable




**Distinctive Features:**
- long/short distinctions


## Grammar

**Word Order:** OVS
**Alignment:** tripartite
**Complexity:** polysynthetic

### Case System

**Count:** 10+ cases
**Cases:** genitive, ergative, accusative, instrumental, ablative, vocative, absolutive, locative, nominative, dative
**Marking:** particles

### Verb System

**Tenses:** imperfect, past, near past, future

**Moods:** imperative, potential

### Noun System

**Gender:** 2 genders
**Number:** singular/dual/plural
**Definiteness:** no articles

## Writing System


This language has no writing system and exists solely in oral tradition.
