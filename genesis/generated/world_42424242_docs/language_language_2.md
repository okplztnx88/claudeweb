# Zaric

*Language of the Norim*

## Overview

**Family:** Descended from ancient classical language
**Speakers:** moderate
**Status:** declining

**Influences:**
- trade language

## Phonology

**Consonants:** simple with 15-20 consonants
**Vowels:** complex with vowel length distinctions
**Syllable Structure:** simple CV structure
**Stress:** fixed on first syllable




**Distinctive Features:**
- creaky voice
- long/short distinctions


## Grammar

**Word Order:** VOS
**Alignment:** ergative-absolutive
**Complexity:** agglutinative

### Case System

**Count:** 2-3 cases
**Cases:** absolutive, accusative
**Marking:** affixes

### Verb System

**Tenses:** future, perfect, past, near past, present
**Aspects:** progressive, completive
**Moods:** optative, conditional, subjunctive, indicative
**Voice:** active, reflexive, causative, passive
**Agreement:** minimal agreement

### Noun System

**Gender:** no grammatical gender
**Number:** singular/dual/plural
**Definiteness:** no articles
**Possession:** alienable/inalienable distinction

## Writing System


This language has no writing system and exists solely in oral tradition.
