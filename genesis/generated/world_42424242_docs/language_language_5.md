# Shalnir

*Language of the Zephari*

## Overview

**Family:** Isolate (no known relations)
**Speakers:** moderate
**Status:** declining

**Influences:**
- conqueror's language

## Phonology

**Consonants:** heavy on stops and nasals
**Vowels:** rich diphthong system
**Syllable Structure:** strict phonotactic rules
**Stress:** fixed on first syllable


**Tone System:** 3-tone system



**Distinctive Features:**
- long/short distinctions
- creaky voice
- nasal vowels


## Grammar

**Word Order:** SOV
**Alignment:** tripartite
**Complexity:** highly analytical

### Case System

**Count:** 4-6 cases
**Cases:** accusative, absolutive, locative, dative
**Marking:** particles

### Verb System

**Tenses:** past, remote future, imperfect, near future, near past
**Aspects:** completive, habitual
**Moods:** potential, imperative
**Voice:** reciprocal, passive, middle, active
**Agreement:** agrees with subject in person and number

### Noun System

**Gender:** 2 genders
**Number:** singular/dual/plural
**Definiteness:** no articles
**Possession:** alienable/inalienable distinction

## Writing System


This language has no writing system and exists solely in oral tradition.
